# NightOwl v0.1.0-alpha.2

This release fixes ZIP extraction on Windows. Download this version if Windows
"Extract all" rejected alpha.1 as invalid or WinRAR reported that it could not
create a folder.

## What changed

The packaging command now writes ordinary relative file paths, without the `./`
directory entries in alpha.1. Release checks reject those entries and verify
extraction with PowerShell's ZIP reader in addition to the application checks.
Chat features and the saved-data format are unchanged.

## Install

Download `nightowl-v0.1.0-alpha.2-windows-x64.zip` and its `.sha256` file. Compare
`Get-FileHash <zip-path> -Algorithm SHA256` with the checksum. Extract normally
with Windows **Extract all** or WinRAR, then open PowerShell in the extracted
folder and run `.\nightowl.exe --setup`. Bun and Node.js are not required.

Use your own OpenRouter API key, or install/start Ollama and download a model
separately. Existing sessions and provider settings are reused; extracting an
updated app does not delete them. Close an older running copy before launching
the new one. Keep the accompanying license files.

Source installation: install Bun 1.4.2, clone the repository, check out
`v0.1.0-alpha.2`, run `bun install --frozen-lockfile`, then `bun run start --setup`.

## Alpha scope

Windows x64 is the binary target; macOS/Linux have source CI coverage. The binary
is unsigned. This remains a chat/continuity harness with provider switching,
local sessions, task notes, context budgets, and text export/import. Coding
tools, shell execution, and subscription authentication are not included.
Compaction is lossy; keep essential facts in `/memory`. Saved data is unencrypted.
Real OpenRouter chat was tested manually; real Ollama inference remains unverified.
See README.md, SECURITY.md, and the alpha.1 notes for the full feature/privacy scope.

# NightOwl v0.1.0-alpha.1

NightOwl's first continuity alpha keeps conversations and task notes locally while
you switch between OpenRouter and Ollama models in the same chat.

## Install

Windows x64: download `nightowl-v0.1.0-alpha.1-windows-x64.zip` and its `.sha256`
file. Compare `Get-FileHash <zip-path> -Algorithm SHA256` with that checksum,
extract the archive, and run `.\nightowl.exe --setup` in PowerShell. The runtime
is included; keep the license files. The executable is unsigned. A checksum
checks integrity, not publisher identity; obtain downloads from this repository.

From source: install Git and Bun 1.4.2, clone the repository, check out
`v0.1.0-alpha.1`, run `bun install --frozen-lockfile`, then `bun run start --setup`.
Windows x64 is the initial binary target. macOS/Linux source CI does not replace
manual terminal and installation verification on those platforms.

Use your own OpenRouter API key, or install/start Ollama separately and download
a model such as `ollama pull llama3.2`. NightOwl does not download models.

## Included

- Streaming replies, stop, saved partial replies, and restart recovery.
- SQLite conversations, session picker, rename, and automatic workspace resume.
- In-chat model switching with provider/model attribution on each reply.
- Context budgets, local excerpt compaction, context inspector, and task notes.
- Versioned JSON export/import for transcript text and current notes.
- Chat and input that fill the terminal width, plus basic Markdown/code display.

## Alpha limitations

This is a chat harness. File editing, shell tools, Plan/Build modes, automatic
provider fallback, and subscription/OAuth authentication are not included.

Compaction uses local excerpts, not model-generated summaries. It is lossy;
put essential constraints in `/memory`. Context estimates are conservative,
not exact model token counts. Switching cannot transfer a model's hidden state.

Real OpenRouter chat has been tested manually. Ollama provider requests and
switching have automated fixture coverage; real Ollama inference has not yet
been verified. Local performance depends on the installed model and hardware.

Exports include title, notes, text, status, and provider/model attribution.
They omit credentials/settings, workspace paths, context limits, saved compaction
records, and request/switch history. Sensitive content in a transcript remains
in the export. Imports create fresh IDs, retain the app's current provider,
restore no active requests, and accept at most 10 MiB of text-session JSON.
Headless imports select no provider. Existing files are never overwritten by export.

Saved sessions, notes, and optional saved credentials are unencrypted local
files. On first launch, schema v1/v2 databases are backed up beside the database
and upgraded to v3. Close other NightOwl processes first. Older builds cannot
open v3 data. See README.md and SECURITY.md for storage and privacy details.

The archive includes dependency notices, the Bun runtime license, and source/
rebuild references. Report sanitized alpha issues through GitHub Issues.

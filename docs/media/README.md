# Terminal demo

`terminal-demo.mp4` is the existing 47-second NightOwl terminal launch edit,
copied from `media/terminal-film/nightowl-terminal-launch.mp4` for the README.
It is 1920 × 1080 at 30 fps, with an original instrumental score and no narration.
`terminal-demo.png` is a frame from that video, used as a clickable preview.

The unmodified Windows release ran under native ConPTY and made real OpenRouter
requests. The session switched from Cohere to Liquid, kept the conversation ID
through the switch and restart, and saved task notes in the actual app. Recorded
terminal bytes were replayed with idle pauses removed, editorial titles, and
camera moves. The video is a recording/replay of a live session.

Ollama appears in the provider picker, but the recording demonstrates switching
OpenRouter models and does not depict local Ollama inference. API keys were kept
out of the recording. Capture used an isolated data directory.

The README uses a linked image and an MP4 link, which GitHub supports without
depending on an HTML `<video>` tag. Click the preview or video link to open the
file; download it if the viewer does not offer playback.
